## Visión general del proyecto

El sitio pertenece a **Flex Membrana Protege**, empresa con base en Pilar, Zona Este. Vende y presenta:

- Revestimientos acrílicos (línea Raya-2 en cuatro texturas)
- Pisos de microcemento (Micropiso)
- Pisos atérmicos para piscinas y bordes
- Accesorios

El cliente puede navegar el catálogo, ver detalle de cada producto, hacer preguntas al vendedor y comprar. Los datos de productos hoy están hardcodeados; la intención es migrarlos a base de datos SQL.
